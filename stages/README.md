# Stages

This directory groups all project materials by course stage.

- `stage1` — task statement report.
- `stage2` — dataset collection/preparation report.
- `stage3` — dataset cleaning, parsing, manifests, and dataset-preparation script.
- `stage4` — baseline experiments and reports.
- `stage5` — final model package and experiment submission materials.
- `stage6` — presentation and supporting bundle.
- `stage7` — defense preparation notes and demo assets.
- `stage8` — final interview preparation memo.
