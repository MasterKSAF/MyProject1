## 2. Python

### 2.1. Встроенные типы данных. `type()`. Приведение типов

- `int` — целые числа, например `5`, `-10`.
- `float` — вещественные числа, например `3.14`.
- `str` — строки, например `"hello"`.
- `bool` — логический тип: `True`, `False`.
- `type(x)` показывает тип объекта.
- Приведение типов: `int("5")`, `float("3.2")`, `str(10)`, `bool(1)`.

Что важно помнить:
- не всякую строку можно перевести в число;
- `bool(0)` дает `False`, почти все остальные значения дают `True`.

### 2.2. Условный оператор

- Основная форма: `if`, `elif`, `else`.
- Используется для выбора действия по условию.
- Условие должно возвращать `True` или `False`.

Пример:
```python
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")
```

### 2.3. Арифметические и логические операции

- Арифметические: `+`, `-`, `*`, `/`, `//`, `%`, `**`.
- Сравнения: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- Логические: `and`, `or`, `not`.

Что полезно проговорить:
- `/` — обычное деление;
- `//` — целочисленное деление;
- `%` — остаток от деления.

### 2.4. Коллекции: `tuple`, `list`, `dict`, `set`

- `list` — изменяемая упорядоченная коллекция.
- `tuple` — неизменяемая упорядоченная коллекция.
- `dict` — словарь вида `ключ: значение`.
- `set` — множество уникальных элементов.

Когда применяются:
- `list` — когда нужны изменение, добавление, удаление;
- `tuple` — когда структура фиксирована;
- `dict` — для хранения данных по ключу;
- `set` — для удаления дублей и быстрых проверок принадлежности.

### 2.5. Переменные и правила именования

- Имя переменной должно начинаться с буквы или `_`.
- Нельзя начинать с цифры.
- Нельзя использовать ключевые слова Python.
- Хорошая практика: понятные имена, например `train_loss`, `image_size`.

### 2.6. Циклы `for` и `while`

- `for` используется, когда перебираем элементы последовательности.
- `while` используется, когда повторяем действия, пока выполняется условие.

Что повторить:
- `break` — выход из цикла;
- `continue` — переход к следующей итерации.

### 2.7. `print()` и `input()`

- `print()` выводит данные на экран.
- `input()` получает строку от пользователя.
- После `input()` часто нужно явное приведение типа, например `int(input())`.

### 2.8. Пользовательские функции. Параметры. `lambda`. Встроенные функции

- Функция объявляется через `def`.
- Может принимать параметры и возвращать значение через `return`.
- `lambda` — короткая анонимная функция.
- Примеры встроенных функций: `len()`, `sum()`, `min()`, `max()`, `range()`.

Что важно:
- понимать разницу между параметрами и аргументами;
- уметь объяснить, зачем функции нужны: переиспользование кода и упрощение структуры программы.

### 2.9. NumPy: индексация, срезы, базовые методы

- `numpy.ndarray` — многомерный массив.
- Индексация: `arr[0]`, `arr[1:5]`, `arr[:, 0]`.
- Частые методы: `reshape`, `sum`, `mean`, `max`, `min`, `astype`.

Что важно:
- NumPy нужен для быстрых численных вычислений;
- массивы поддерживают векторные операции.

### 2.10. NumPy: операции, типы данных, маскирование

- Поэлементные операции: `arr + 1`, `arr * 2`.
- Типы: `int32`, `float32`, `float64`.
- Маска — булев массив для фильтрации.

Пример:
```python
mask = arr > 0
positive = arr[mask]
```

### 2.11. Matplotlib

- Используется для визуализации данных.
- Базовые функции: `plot`, `imshow`, `hist`, `scatter`, `title`, `xlabel`, `ylabel`, `legend`, `show`.

Для собеседования полезно уметь словами объяснить:

### 2.12. Модули: встроенные и пользовательские

- Модуль — файл с Python-кодом.
- Импорт: `import math`, `from math import sqrt`.
- Пользовательский модуль — собственный `.py` файл с функциями и классами.

### 2.13. Pandas

- Основные структуры: `Series` и `DataFrame`.
- Частые методы: `head`, `info`, `describe`, `shape`, `columns`, `value_counts`.
- Частые операции: фильтрация, выбор столбцов, группировка.

### 2.14. List comprehension

- Краткий способ создавать списки.

Пример:

Плюсы:

- читаемость при простых преобразованиях.

### 2.15. Основы ООП

- Класс — шаблон объекта.
- Объект — экземпляр класса.

## 3. Нейронные сети

### 3.1. Активационные функции

- `ReLU` — обнуляет отрицательные значения, часто используется в скрытых слоях.
- `sigmoid` — дает значения от 0 до 1, часто в бинарной классификации.
- `softmax` — преобразует выход в вероятности по классам.
- `tanh` — значения от -1 до 1.

### 3.2. Обучение сети. Функции ошибки. Метрики

- Обучение — это подбор весов для уменьшения ошибки.
- Функция ошибки показывает, насколько предсказание отличается от правильного ответа.
- Примеры loss: `MSE`, `binary_crossentropy`, `categorical_crossentropy`.
- Метрика — показатель качества модели, например `accuracy`.

Важно проговорить:
- loss оптимизируется;
- metric обычно только оценивается.

### 3.3. Выборки и оценка модели

- `train` — для обучения;
- `val` — для подбора параметров и контроля переобучения;
- `test` — для финальной оценки.

### 3.4. Классификация

- Цель: определить класс объекта.
- На выходе обычно число нейронов равно числу классов.
- Для многоклассовой классификации часто используют `softmax`.

### 3.5. Переобучение

- Модель слишком хорошо запоминает train и хуже работает на новых данных.
- Признак: train-метрика растет, а val-метрика перестает расти или падает.

Как бороться:
- аугментация;
- dropout;
- регуляризация;
- early stopping;
- больше данных;
- упрощение модели.

### 3.6. Dense

- Полносвязный слой.
- Каждый выходной нейрон связан со всеми входными.
- Основной параметр: число нейронов.

Размерность:
- если вход `(None, n)`, выход `(None, units)`;
- если вход `(None, t, n)`, Dense применяется к последней оси и дает `(None, t, units)`.

### 3.7. Conv2D и MaxPool2D

- `Conv2D` выделяет локальные признаки на изображении.
- Основные параметры: число фильтров, размер ядра, `padding`, `strides`.
- `MaxPool2D` уменьшает пространственные размеры и оставляет наиболее сильные признаки.

### 3.8. Аугментация изображений

- Нужна для повышения устойчивости модели и борьбы с переобучением.
- Примеры: поворот, отражение, сдвиг, масштабирование, изменение яркости.

### 3.9. Tokenizer

- Преобразует текст в последовательности индексов.
- Используется перед Embedding и рекуррентными слоями.
- Важные параметры: размер словаря, `oov_token`, фильтры.

### 3.10. Bag of Words

- Текст представляется вектором частот слов.
- Не учитывает порядок слов.
- Подходит для простых задач классификации текста.

### 3.11. Embedding

- Преобразует индексы слов в плотные векторы признаков.
- Важные параметры: размер словаря и размер embedding-вектора.
- Если вход `(None, L)`, выход `(None, L, D)`.

### 3.12. Регрессия

- Задача предсказания числового значения.
- Примеры: цена квартиры, температура, спрос.
- Часто используются `MSE`, `MAE`.

### 3.13. Временные ряды

- Данные зависят от времени.
- Важно сохранять порядок.
- Часто используются окна наблюдений.
- Подходящие модели: LSTM, GRU, 1D-CNN.

### 3.14. Сегментация. U-Net

- Сегментация — это классификация каждого пикселя.
- U-Net состоит из encoder и decoder с skip-connections.
- Используется в медицине, спутниковых снимках, техническом зрении.

### 3.15. LSTM и RNN

- RNN учитывают последовательность.
- LSTM лучше работает с длинными зависимостями.
- Может возвращать:
  - только последний выход;
  - всю последовательность;
  - скрытые состояния.

### 3.16. Методы распознавания и генерации речи

- Распознавание речи: аудио в текст.
- Генерация речи: текст в аудио.
- Часто используются спектрограммы, RNN, Transformer-подходы.

### 3.17. ChatGPT. Дообучение. Роли

- ChatGPT — языковая модель для генерации текста.
- Дообучение — адаптация модели под задачу или домен.
- Роль в промпте задает стиль поведения модели.

### 3.18. Object Detection

- Detection — не только класс, но и координаты объекта.
- Данные размечаются bounding boxes.
- Примеры моделей: YOLO, Faster R-CNN, DETR.

### 3.19. TensorFlow

- TensorFlow — библиотека для работы с тензорами и нейронными сетями.
- Тензор имеет форму, тип данных и устройство.
- Важно понимать базовые операции и построение модели.

### 3.20. PyTorch

- PyTorch — библиотека для нейросетей с удобной динамической графикой вычислений.
- Нужно понимать:
  - создание тензоров;
  - `shape`;
  - перенос на устройство;
  - обучение модели;
  - оптимизатор;
  - проход `forward`.

## 4. Размерности тензоров и слоев

Это один из самых важных блоков. Его лучше реально прорешать руками.

### 4.1. Dense

- Вход `(None, features)` -> выход `(None, units)`.
- Вход `(None, time, features)` -> выход `(None, time, units)`.

### 4.2. Flatten

- Склеивает все пространственные оси в одну.
- Пример: `(None, 10, 20, 3)` -> `(None, 600)`.

### 4.3. Embedding

- `(None, sequence_length)` -> `(None, sequence_length, embedding_dim)`.

### 4.4. Conv1D

- Меняет число каналов на число фильтров.
- При `padding='same'` длина обычно сохраняется, если `stride=1`.

Пример:
- `(None, 100, 20)` -> `Conv1D(32, ...)` -> `(None, 100, 32)`.

### 4.5. Conv2D

Если вход `(None, H, W, C)`:
- число каналов на выходе равно числу фильтров;
- высота и ширина зависят от `kernel_size`, `padding`, `strides`.

При `padding='same'` и `stride=1`:
- `(H, W)` сохраняются.

При `padding='valid'`:
- размер уменьшается.

### 4.6. MaxPool2D

- Уменьшает пространственные размеры.
- Часто в 2 раза при стандартном пуллинге `2x2`.

Пример:
- `(None, 128, 128, 32)` -> `(None, 64, 64, 32)`.

### 4.7. LSTM

- Если `return_sequences=False`, выход `(None, units)`.
- Если `return_sequences=True`, выход `(None, time, units)`.
- Если `return_state=True`, дополнительно возвращаются скрытые состояния.

### 4.8. GRU

- По логике размерностей похож на LSTM.
- Если без `return_sequences`, выход `(None, units)`.

### 4.9. Concatenate

- Склеивает тензоры по выбранной оси.
- Все остальные оси должны совпадать.

Пример:
- `(None, 100, 100)` и `(None, 100, 100)` при `axis=1`
- результат `(None, 200, 100)`.

### 4.10. Что нужно уметь делать быстро

- считать выход после каждой операции;
- понимать, какая ось за что отвечает;
- не путать число фильтров с пространственными размерами;
- помнить, что `Dense` меняет последнюю ось;
- помнить, что `Embedding` добавляет ось признаков.
