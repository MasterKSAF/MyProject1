# MyProject1

AI/ML graduation project repository organized by stage.

## Structure

- `DB/` — shared local dataset used across multiple stages.
- `stages/stage1` — stage 1 report.
- `stages/stage2` — stage 2 report.
- `stages/stage3` — dataset preparation materials, parsing notebook, manifests, and local legacy artifacts.
- `stages/stage4` — baseline training materials, reports, notebooks, and stage 4 script.
- `stages/stage5` — final model package, stage 5 report, and supporting script.
- `stages/stage6` — presentation files and support bundle used for presentation work.
- `stages/stage7` — defense notes, demo materials, scripts, and voice reference files.
- `stages/stage8` — final interview preparation memo and builder script.
- `scripts/` — compatibility wrappers for the main runnable scripts after reorganization.

## Notes

- The repository keeps stage-specific artifacts inside `stages/` for easier navigation.
- Shared assets that are reused across multiple stages stay at the project root.
- Some local-only folders such as previews or legacy copies are intentionally excluded from Git.
