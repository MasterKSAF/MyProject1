Этот архив подготовлен для другой LLM, чтобы она помогла заполнить шаблон презентации для защиты проекта.

Что внутри:

1. `docs/4.docx`
Отчёт по этапу 4. В нём есть постановка задачи, описание базы, baseline-модель и первые результаты.

2. `docs/5.docx`
Отчёт по этапу 5. В нём есть итог по финальной модели, ссылки на ноутбуки и описание состава папки этапа 5.

3. `docs/stage5_submission_ru.md`
Текстовая краткая сводка по этапу 5.

4. `notebooks/stage5_experiments_colab.ipynb`
Colab-ноутбук с экспериментами. В нём сравнивались несколько архитектур моделей.

5. `notebooks/stage5_final_inference_colab.ipynb`
Финальный Colab-ноутбук для использования выбранной модели.

6. `notebooks/stage5_package_README.md`
Краткое описание папки этапа 5 и используемых файлов.

7. `visuals/training_history_stage4.png`
График обучения baseline-модели. Его можно использовать в презентации на слайде с первым результатом.

8. `visuals/confusion_matrix_stage4.png`
Матрица ошибок baseline-модели. Её можно использовать как дополнительный визуал.

9. `visuals/comparison_stage5.png`
Визуал сравнения моделей этапа 5. Его можно использовать на слайде со сравнением архитектур.

10. `data/comparison_stage5.csv`
Таблица результатов по экспериментам этапа 5.

Что нужно получить от другой LLM:

- подробную раскладку по слайдам именно под данный шаблон презентации;
- для каждого слайда:
  - заголовок;
  - короткий текст;
  - что вставить визуально;
  - как адаптировать слайд шаблона под этот проект;
- при необходимости рекомендации, какие слайды объединить или сократить.

Лучше ориентироваться на презентацию примерно на 10-12 слайдов и выступление на 10-17 минут.
